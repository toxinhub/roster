রোস্টার সম্পাদনা

এখানে পরিবর্তন করলে সাথে সাথে লাইভ সাইটে আপডেট হবে না — নিচের ধাপ অনুসরণ করুন
যেভাবে কাজ করে: নিচের টেবিলে যে কারো যেকোনো দিনের শিফট বদলান (ড্রপডাউন থেকে OFF বেছে নিলে ছুটি হয়ে যাবে), প্রয়োজনে নতুন কর্মী বা নতুন তারিখ যোগ করুন। তারপর "কোড তৈরি করুন"-এ চাপুন, পুরো কোডটা কপি করুন, GitHub রিপোজিটরির schedule.js ফাইল খুলে (পেন্সিল আইকনে ক্লিক) পুরনো লেখা মুছে এটা পেস্ট করে Commit করুন। ১ মিনিটের মধ্যে লাইভ সাইট আপডেট হয়ে যাবে।
