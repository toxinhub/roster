রোস্টার সম্পাদনা

শিফটে ক্লিক করুন, নতুন কোড বাছুন — সংরক্ষণ চাপলেই লাইভ সাইটে চলে যাবে
যাচাই করা হচ্ছে…
⚙️ GitHub সংযোগ সেটআপ (একবার করলেই হবে) ▾
এক-ক্লিকে সংরক্ষণ করতে চাইলে একটা GitHub টোকেন দরকার — এটা একবার বানিয়ে এখানে বসিয়ে দিলে পরে থেকে শুধু ক্লিক করেই শিফট বদলানো যাবে, GitHub-এ গিয়ে আর কোড পেস্ট করতে হবে না।

টোকেন যেভাবে বানাবেন:
১. এই লিংকে যান: github.com/settings/personal-access-tokens/new
২. Repository access এ "Only select repositories" বেছে আপনার রোস্টার রিপোজিটরি সিলেক্ট করুন
৩. Permissions → Repository permissions → Contents এ "Read and write" বাছুন
৪. নিচে Generate token চাপুন, যে কোডটা দেখাবে (শুরু হয় github_pat_ দিয়ে) সেটা কপি করে নিচে পেস্ট করুন

নিরাপত্তা: এই টোকেন শুধু আপনার এই ব্রাউজারে সংরক্ষিত থাকবে (localStorage), অন্য কারো কাছে যাবে না। পাবলিক/শেয়ার করা কম্পিউটারে এটা ব্যবহার না করাই ভালো। যেকোনো সময় GitHub থেকে টোকেনটা বাতিল করতে পারবেন।
টোকেন সেটআপ না করে থাকলে এই কোডটা কপি করে GitHub রিপোজিটরির schedule.json ফাইলে গিয়ে পুরনো লেখা মুছে পেস্ট করে Commit করুন।
