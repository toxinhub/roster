# ডিউটি রোস্টার ওয়েবসাইট — GitHub Pages দিয়ে চালু করার নিয়ম

এই ফোল্ডারে ৪টা ফাইল আছে:

- `index.html` — লাইভ রোস্টার পেজ (সবাই এই লিংকেই দেখবে)
- `admin.html` — শিফট বদলানোর জন্য সম্পাদনা পেজ
- `schedule.js` — আসল ডেটা (নাম, তারিখ, শিফট)
- `style.css` — ডিজাইন

## ধাপ ১: GitHub-এ রিপোজিটরি তৈরি করুন

1. [github.com](https://github.com) -এ লগইন করুন (অ্যাকাউন্ট না থাকলে ফ্রি তৈরি করে নিন)
2. উপরে ডানদিকে **+** আইকনে ক্লিক করে **New repository** বাছুন
3. নাম দিন, যেমন `roster` — **Public** সিলেক্ট থাকতে হবে
4. **Create repository** চাপুন

## ধাপ ২: ফাইলগুলো আপলোড করুন

1. নতুন রিপোজিটরির পেজে **Add file → Upload files** চাপুন
2. এই ৪টা ফাইল (`index.html`, `admin.html`, `schedule.js`, `style.css`) টেনে এনে ছাড়ুন
3. নিচে **Commit changes** চাপুন

## ধাপ ৩: GitHub Pages চালু করুন

1. রিপোজিটরির উপরে **Settings** ট্যাবে যান
2. বামপাশে **Pages** এ ক্লিক করুন
3. **Branch** এর নিচে `main` এবং `/ (root)` বাছুন, তারপর **Save**
4. কিছুক্ষণ পর একটা লিংক দেখাবে, যেমন:
   `https://আপনার-ইউজারনেম.github.io/roster/`

এই লিংকটাই সবাইকে শেয়ার করুন — এখানে গেলেই লাইভ রোস্টার দেখা যাবে, কোনো লগইন লাগবে না।

## শিফট / অফ পরিবর্তন করবেন যেভাবে

1. আপনার লাইভ লিংকের শেষে `admin.html` যোগ করে খুলুন, যেমন:
   `https://আপনার-ইউজারনেম.github.io/roster/admin.html`
   *(এই পেজের লিংক কাউকে না দিলে সাধারণ দর্শকরা এটা দেখবে না — তবে এটা পাসওয়ার্ড-সুরক্ষিত না, তাই লিংকটা সাবধানে রাখুন)*
2. যার শিফট বদলাবেন তার নামের সারিতে গিয়ে সংশ্লিষ্ট তারিখের ড্রপডাউন থেকে নতুন কোড বাছুন — ছুটি দিতে চাইলে **OFF** বাছুন
3. নতুন কর্মী বা নতুন তারিখ লাগলে উপরের বাটন থেকে যোগ করুন
4. **কোড তৈরি করুন** চাপুন, তারপর **কপি করুন**
5. GitHub রিপোজিটরিতে ফিরে গিয়ে `schedule.js` ফাইলে ঢুকুন, উপরে পেন্সিল (✏️) আইকনে ক্লিক করুন
6. ভেতরের সব লেখা মুছে কপি করা কোডটা পেস্ট করুন
7. নিচে **Commit changes** চাপুন

প্রায় ৩০-৬০ সেকেন্ডের মধ্যে লাইভ সাইট নতুন তথ্য দেখাবে — রিফ্রেশ দিলেই বোঝা যাবে।

## নোট

- `A`, `B`, `C` শিফটের সময় (যেমন সকাল/বিকাল/রাত) এখনো নির্দিষ্ট করা নেই — `schedule.js` ফাইলে `shiftTypes` অংশে প্রতিটা কোডের পাশে `note` এ আসল সময় লিখে দিতে পারবেন, সেটা ওয়েবসাইটের লেজেন্ডে দেখাবে।
- চাইলে `shiftTypes`-এ সম্পূর্ণ নতুন কোডও যোগ করা যাবে (যেমন `D` নামে আরেকটা শিফট)।
