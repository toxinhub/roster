# ডিউটি রোস্টার ওয়েবসাইট — আপডেটেড ভার্সন

এই ফোল্ডারে ৫টা ফাইল আছে:

- `index.html` — লাইভ রোস্টার পেজ (ডেস্কটপে টেবিল, ফোনে আলাদা কার্ড আকারে — দুটোই এই একই ফাইল থেকে চলে)
- `admin.html` — শিফট বদলানোর পেজ, এখন ক্লিক করেই বদলানো যায়
- `schedule.json` — আসল ডেটা (আগে ছিল `schedule.js`, এখন `schedule.json`)
- `style.css` — ডিজাইন
- `README.md` — এই নির্দেশিকা

## ⚠️ আগে থেকে সাইট লাইভ থাকলে (আপডেট করছেন)

আপনার রিপোজিটরিতে আগের `schedule.js` ফাইলটা এখন আর ব্যবহার হবে না — নতুন ফাইলগুলো `schedule.json` ব্যবহার করে। তাই:

1. এই ৫টা ফাইল GitHub রিপোজিটরিতে আপলোড করুন (নিচের ধাপ ২ দেখুন) — পুরনো `index.html`, `admin.html`, `style.css` এর জায়গায় ওভাররাইট হয়ে যাবে
2. পুরনো `schedule.js` ফাইলটা রিপো থেকে ডিলিট করে দিতে পারেন (থাকলেও ক্ষতি নেই, শুধু অব্যবহৃত পড়ে থাকবে)
3. আপনার আগের শিফট ডেটা এই নতুন `schedule.json`-এ আগে থেকেই বসানো আছে (আরমান/তন্ময়/আশিক, ২৫ সেপ্টেম্বর–১ অক্টোবর) — কিছু হারাবে না

নতুন করে সাইট বানাচ্ছেন হলে নিচের সব ধাপ অনুসরণ করুন।

## ধাপ ১: GitHub-এ রিপোজিটরি তৈরি করুন

1. [github.com](https://github.com) -এ লগইন করুন (না থাকলে ফ্রি অ্যাকাউন্ট খুলুন)
2. উপরে ডানদিকে **+** → **New repository**
3. নাম দিন, যেমন `roster` — **Public** নিশ্চিত করুন
4. **Create repository**

## ধাপ ২: ফাইলগুলো আপলোড করুন

1. **Add file → Upload files**
2. এই ৫টা ফাইল টেনে এনে ছাড়ুন
3. **Commit changes**

## ধাপ ৩: GitHub Pages চালু করুন

1. **Settings → Pages**
2. **Branch**: `main`, **/ (root)** — **Save**
3. কিছুক্ষণ পর একটা লিংক পাবেন: `https://আপনার-ইউজারনেম.github.io/roster/`

এই লিংকটাই সবাইকে শেয়ার করুন। ফোনে খুললে আপনা-আপনি কার্ড-আকারে, কম্পিউটারে টেবিল-আকারে দেখাবে।

## শিফট / অফ বদলানো — এখন এক ক্লিকে

`admin.html` পেজে ঢুকলে দুইভাবে কাজ করতে পারবেন:

### উপায় ১ (সুপারিশকৃত): এক-ক্লিক সংরক্ষণ

একবার সেটআপ করলে এরপর থেকে শুধু ক্লিক করে সাথে সাথে লাইভ সাইটে পাঠানো যাবে, GitHub-এ গিয়ে কোড পেস্ট করার দরকার নেই।

**সেটআপ (একবারই লাগবে):**

1. `admin.html` খুলে উপরের **"GitHub সংযোগ সেটআপ"** প্যানেলে যান
2. [এই লিংকে](https://github.com/settings/personal-access-tokens/new) গিয়ে একটা টোকেন বানান:
   - **Repository access** → "Only select repositories" → আপনার `roster` রিপো বেছে নিন
   - **Permissions → Repository permissions → Contents** → "Read and write"
   - **Generate token** চাপুন, `github_pat_...` দিয়ে শুরু হওয়া কোডটা কপি করুন
3. `admin.html`-এ ফিরে এসে আপনার GitHub ইউজারনেম, রিপোজিটরির নাম (`roster`), এবং টোকেনটা বসিয়ে **"সংযোগ সংরক্ষণ করুন"** চাপুন

**এরপর থেকে প্রতিবার:**

1. যেকোনো শিফটে ক্লিক করুন — একটা ছোট মেনু খুলবে (A / B / C / OFF)
2. পছন্দমতো একটা বেছে নিন — সাথে সাথে বদলে যাবে
3. নিচে **"✓ সংরক্ষণ করুন (লাইভ সাইটে পাঠান)"** চাপুন
4. ৩০-৬০ সেকেন্ডের মধ্যে লাইভ সাইটে দেখা যাবে

### উপায় ২ (টোকেন ছাড়া): ম্যানুয়াল কপি-পেস্ট

টোকেন সেটআপ করতে না চাইলে, শিফট বদলে **"বা কোড ম্যানুয়ালি কপি করুন"** চাপুন, কোডটা কপি করে GitHub রিপোর `schedule.json` ফাইলে (পেন্সিল আইকন) পেস্ট করে Commit করুন।

## নিরাপত্তা নোট

- টোকেনটা শুধু আপনার ব্রাউজারে সংরক্ষিত থাকে (অন্য কারো ডিভাইসে যায় না)
- `admin.html` লিংক পাসওয়ার্ড-সুরক্ষিত নয় — শুধু যাদের এডিট করা দরকার তাদের দিন
- টোকেন সন্দেহজনক মনে হলে GitHub-এর [Settings → Developer settings → Personal access tokens](https://github.com/settings/tokens?type=beta) থেকে যেকোনো সময় বাতিল করতে পারবেন

## নোট

- `A`, `B`, `C` শিফটের আসল সময় এখনো লেখা নেই — `schedule.json`-এর `shiftTypes` অংশে প্রতিটার `note`-এ সময় লিখে দিলে সাইটের লেজেন্ডে দেখাবে (admin.html দিয়ে ডেটা পাল্টালে এটাও অটো বসে যাবে ফাইলে, চাইলে সরাসরি GitHub-এও এডিট করা যায়)
- নতুন শিফট কোড (যেমন `D`) লাগলে `schedule.json`-এর `shiftTypes`-এ যোগ করুন — admin.html-এর পপ-আপ মেনুতেও অটো দেখাবে
